# Fixture table for the A.2 pending-work check (recipes/session-end-consolidate.md), run through BOTH
# shells: tests/capture-floor/run.sh and run.ps1 read this file, build each brain, run the script in
# the given mode, and compare. One table = sh/PowerShell parity by construction.
#
# name | setup | mode | expect
#   setup (comma-separated, applied in order; empty = a brain with an empty journal and an empty playgrounds/):
#     crumbs=N   append N lowercase "breadcrumb: touched a.md" lines to journal/_current.md
#     crumbcase  append one "Breadcrumb:" line (wrong case: must NOT count)
#     pg         create playgrounds/task/ (an open playground)
#     pgz        also create playgrounds/Zed/ and "playgrounds/a b/" (byte order: Zed < a b < task)
#     archive    create playgrounds/archive/old/ (finished work: must NOT count)
#     ledger     create journal/_activity/<x>.log with boot/stop lines (bookkeeping: must NOT count)
#     bare       a brain with knowledge/ only: no journal, no playgrounds/
#     nobrain    no .synaptic/ at all
#     pgfile     playgrounds is a FILE, not a directory (must NOT count, no error)
#   liveness (K1, v1.7):
#     sid=X      the run under test gets the hook stdin {"session_id":"X"} (default: empty stdin = no id)
#     boot=X     first run the script in mode rescue with session id X (session X starts and sees the state)
#     beat=X     first run the script in mode beat with session id X (a Stop of session X)
#     end=X      first run the script in mode end with session id X (a SessionEnd of session X)
#     age=X      give journal/_activity/.live/X an old mtime (a heartbeat past the 2 h TTL)
#     degraded   write one journal/_activity/_degraded line (a hook failed earlier)
#     livefile   journal/_activity/.live is a FILE (the heartbeat write fails)
#     endedfile  journal/_activity/.ended is a FILE (the end-marker write fails)
#   expect: ';'-separated; every item must hold, and the exit code is always 0:
#     quiet      no stdout and no stderr
#     say:S      stdout contains S          nosay:S   stdout does not contain S
#     has:P      .synaptic/P exists         no:P      .synaptic/P does not exist
#     owner:X    session X is a claimant in journal/_activity/.owner   notowner:X  it is not
#     sig:S      line 1 of journal/_activity/.owner is exactly S (the same literal in both shells = parity)
