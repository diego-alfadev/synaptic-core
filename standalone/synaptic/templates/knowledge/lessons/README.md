# Lessons

Lessons are atomic nodes with `type: lesson`. Each captures a dated, generalizable insight from real work — what happened, why it matters, and what to do differently. They are not incident reports; strip the anecdote, keep the reusable principle.

**Template:** use `templates/lesson.md` for each new lesson node.
